# Morfometria em QGIS

Repositório de apoio aos arquivos utilizados em simulações e análises morfométricas no QGIS.

## Contexto
O projeto reúne materiais geoespaciais e arquivos auxiliares para exercícios de análise espacial e morfometria. A interpretação dos resultados depende do sistema de referência, da escala, da resolução e da qualidade dos dados de origem.

## Como começar
1. Abra os arquivos no QGIS em uma versão compatível.
2. Confira o sistema de coordenadas e as unidades de medida.
3. Verifique a proveniência dos dados antes de reutilizar ou publicar resultados.

Material de estudo e pesquisa; consulte os arquivos disponíveis para conhecer o escopo exato da simulação.
